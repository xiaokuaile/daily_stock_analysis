# 美股行情与认证修复升级说明

本补丁基于 2026 年 6 月 4 日代码 `8df69fe036387d1e72c217cba951b03db74fad92`，只回移已审查的美股数据与维护工作流修复，并封闭通用配置修改认证状态的入口。它不会启用选股、ETF 轮动、定时任务、通知或券商操作。

## 数据行为

- yfinance 股息返回单列 DataFrame 时先转换为 Series，避免分配息事件被静默丢弃。它改善 VOO、QQQ、QQQM 的分配数据解析，不新增完整美国 ETF 基本面模型。
- 公司季度同比按去年对应季度日期匹配，允许 45 天报告日偏移；找不到对应季度时返回缺失并使用既有降级，不再把错误列当去年同季度。
- 美股实时报价复用已有 info 请求，解析可用 PE/PB；估值字段缺失或非法不会丢弃有效价格。ETF 的来源估值口径仍需单独核对，不应当作基金自身公司利润。
- 普通美股日线链使用各来源优先级，`YFINANCE_PRIORITY=0` 对普通链生效；美股指数固定首选和已配置 Longbridge 首选规则保留。
- Longbridge 历史量比请求使用关键字参数，兼容不同 SDK 的参数位置差异。Linux Python 3.11 的容器使用 0.2.74；其他受支持运行环境使用 4.x。LiteLLM 上限收敛为 `<1.99.0`，保留已有隔离版本排除。

## 认证与维护工作流

关闭认证需要在专用认证设置入口提供当前管理员密码，已有登录会话不能替代密码复核。通用配置更新和导入不得改变认证状态；备份导入包含与现有状态等价的认证值时保留原值。写入前完整校验整个请求，拒绝会混淆环境变量行边界的输入，不因部分字段失败写入其他字段。

PR Review 改为手动按 PR 编号触发，仅通过 GitHub API 获取 PR diff，并运行可信默认分支中的审查脚本；不检出或执行 fork PR 代码。正常 CI 保留 `pull_request` 触发。这个调整不改变每日分析、发布、通知或 Secrets。

## 验证与保留边界

运行 `./scripts/ci_gate.sh`，并验证认证 API、配置更新/导入、数据路由和 Web 认证设置组件。离线测试核验来源响应解析与代码行为；真实报价、分红和授权数据源仍须另行只读对账。

Web/桌面旧锁文件与未锁定的 Python 间接依赖仍可能命中公开公告。本补丁不是完整依赖安全升级，尤其不包含 Electron 大版本迁移。部署或对外暴露服务前需要另外完成依赖更新、认证配置及目标环境测试。

完整上游版本增加 API/schema、数据库和调度行为变化，并有尚未关闭的本地验证问题，不能用本补丁通过的测试替代全量升级验收。新增 `--etf-rotation` 只适用于 A 股交易日历与境内 ETF，当前不回移该功能。
